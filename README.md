Arnaud Energies — Générateur de dossiers photovoltaïques
Application web autonome pour générer automatiquement les dossiers commerciaux à partir des études AutoCalSol.
Fonctionnalités

📄 Import PDF AutoCalSol — extraction automatique des données
💶 Saisie financement (mensualités HT ou comptant)
📊 Simulation rentabilité 30 ans — mode Lissé ou Réel an/an
🎛️ Curseurs what-if (tarif, inflation, mensualité)
🧾 Génération Proposition PDF (format Arnaud Energies)
📋 Génération Contrat DOCX
📊 Génération Présentation PPTX
